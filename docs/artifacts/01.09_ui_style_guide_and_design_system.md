## 🎨 1. Design Philosophy & Architectural Rules

1. **Zero External Framework Runtimes**: All UI components are Vanilla TypeScript Custom Elements (`HTMLElement`). No React, Vue, or Angular bundles.
2. **Native Thunderbird Supernova Tokens**: Components hook into Thunderbird’s native CSS custom properties with strict fallbacks, guaranteeing pixel-perfect alignment across Light, Dark, and High-Contrast OS themes.
3. **RAII Lifetime Binding**: Every component must instantiate an `EventSubscriptionScope` in `connectedCallback()` and release it in `disconnectedCallback()` via `this.scope[Symbol.dispose]()`.
4. **Resilient Error Boundaries**: `render()` calls must be guarded so that failures display a recoverable fallback card with a direct link to the **AI Diagnostic Exporter**.
5. **Deterministic Accessibility**: All interactive buttons require explicit `aria-label` or `title`, valid focus outlines (`2px solid var(--color-accent)`), and a minimum click target of `32x32px`.

## 🛡️ 5. Standard Error Boundary Pattern

Every custom element must implement this pattern to prevent silent rendering crashes:

```typescript
export class BaseWebComponent extends HTMLElement {
  protected safeRender(renderFn: () => void): void {
    try {
      renderFn();
    } catch (error: any) {
      console.error(`[UI-Crash] Error in <${this.tagName.toLowerCase()}>:`, error);
      this.innerHTML = `
        <div class="component-crash-boundary">
          <div class="crash-icon">⚠️</div>
          <div class="crash-body">
            <h4>Component Render Error</h4>
            <p>${error.message || 'An unexpected rendering error occurred in this view.'}</p>
            <div class="crash-actions">
              <button type="button" class="btn btn-secondary btn-sm" onclick="this.closest('${this.tagName.toLowerCase()}').connectedCallback()">
                🔄 Retry View
              </button>
            </div>
          </div>
        </div>
      `;
    }
  }
}
```

## ⚡ 6. Component Checklist for Ongoing Development

Before shipping any new view or component:
- [ ] Uses CSS tokens (`var(--color-...)`) — zero hardcoded hex values in component styling
- [ ] Light / Dark mode verified in Thunderbird 128+ ESR
- [ ] RAII cleanup verified in `disconnectedCallback()`
- [ ] Keyboard accessible (Tab navigation, Enter/Space activation, Esc closes modals)
- [ ] Interactive controls covered by a matching test in `tests/ui/*.test.ts`
- [ ] Error boundary handles unexpected runtime exceptions gracefully
