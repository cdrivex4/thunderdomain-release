## 🔍 Detailed Gap Analysis

While the core architecture, compliance suite, Web Components, and button test pipelines are scaffolded, the following **6 production-readiness gaps** have been identified and must be implemented:

```
+------------------------------------+---------------------------------------------------------------+
| Identified Gap                     | Technical Requirement & Remediation Strategy                  |
+------------------------------------+---------------------------------------------------------------+
| 1. Extension Assets & SVG Icons    | Missing visual icon assets referenced by `manifest.json` and |
|                                    | `<spaces-rail>` (16px, 32px, 48px, 128px + Spaces SVGs).      |
| 2. OAuth2 / PKCE Auth Flow Module  | Need dedicated `src/api/graph/auth.ts` implementing the       |
|                                    | interactive browser popup / `identity.launchWebAuthFlow`.     |
| 3. Master Categories Sync Service  | Need `src/api/graph/categories.ts` for bidirectional Outlook  |
|                                    | Master Categories (`/masterCategories`) & Thunderbird tags.   |
| 4. Real `.xpi` Zip Packaging       | `scripts/package-xpi.js` needs native zip archive compression |
|                                    | to produce installable `.xpi` extension files.               |
| 5. Repository Hygiene Files        | Missing `.gitignore`, `.prettierrc`, and `.eslintrc.json`.    |
| 6. Unified Exports & Index Hubs    | Need `index.ts` barrel files across `src/common/`,            |
|                                    | `src/api/`, and `src/storage/`.                               |
+------------------------------------+---------------------------------------------------------------+
```

---

## 🛠️ Remediation Action Plan

1. **Create SVG Icon Suite** in `assets/icons/` (`mail.svg`, `calendar.svg`, `tasks.svg`, `notes.svg`, `delegation.svg`, `app-icon.svg`).
2. **Implement `src/api/graph/auth.ts`** with PKCE code verifier, challenge generation, and token refresh.
3. **Implement `src/api/graph/categories.ts`** for bi-directional category color synchronization.
4. **Upgrade `scripts/package-xpi.js`** with cross-platform compression (`adm-zip` / native node streaming zip).
5. **Add `.gitignore`, `.prettierrc`, and `.eslintrc.json`**.
6. **Add Barrel Exports** (`src/common/index.ts`, `src/api/index.ts`, `src/storage/index.ts`).
