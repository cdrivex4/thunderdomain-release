## 2. Executive Delegation ("Secretary" / Boss Workflow)

```mermaid
sequenceDiagram
    autonumber
    actor Sec as Executive Assistant / Secretary
    participant Ext as Outlook Suite Extension
    participant Auth as DICT / M365 Identity (ad.gov.sc)
    participant Graph as MS Graph / Exchange Engine
    participant TB as Thunderbird Spaces & UI

    Sec->>Ext: Open Executive Delegation Manager
    Sec->>Ext: Request access to Boss Profile (boss@gov.sc)
    Ext->>Auth: Verify delegated OAuth token / AD permissions
    Auth-->>Ext: Validated Delegated Scopes (Mail.ReadWrite.Shared, Calendars.ReadWrite.Shared)
    
    Ext->>Graph: Query `/v1.0/users/boss@gov.sc/calendars` & `/mailFolders`
    Graph-->>Ext: Return Boss Mailbox tree, Events & Category definitions
    
    Ext->>TB: Mount Boss Calendar as Overlay (color-coded)
    Ext->>TB: Register "Send on Behalf of Boss" action in Compose window
    
    Note over Sec,TB: Secretary can now switch context instantly or view side-by-side
    Sec->>Ext: Create meeting invite on behalf of Boss
    Ext->>Graph: POST `/v1.0/users/boss@gov.sc/events`
    Graph-->>Ext: 201 Created (Sent as "Sec on behalf of Boss")
    Ext->>TB: Instant UI feedback & event confirmation
```
